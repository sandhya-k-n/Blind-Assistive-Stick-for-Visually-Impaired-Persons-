# Fall Detection and Power Optimization for Smart Assistive Stick

## 📌 Overview

This project is a smart assistive stick designed to improve the safety and independence of visually impaired users.

The system combines obstacle detection, fall detection, GPS location tracking and GSM-based emergency communication using an ESP32 microcontroller.

## 🚀 Features

- Obstacle detection
- Fall detection
- GPS location tracking
- Emergency SMS communication
- Sensor-based monitoring
- Power optimization

## 🔧 Hardware Used

- ESP32
- HC-SR04 Ultrasonic Sensor
- MPU6050 Accelerometer & Gyroscope
- SIM800L GSM Module
- NEO-6M GPS Module
- Lithium-Ion Battery

## 💻 Software & Technologies

- Embedded C / Arduino
- ESP32
- Arduino IDE
- Sensor interfacing
- UART communication
- GPS and GSM communication

## ⚙️ Working Principle

1. The HC-SR04 ultrasonic sensor detects obstacles in front of the stick.
2. The MPU6050 monitors acceleration and orientation.
3. The ESP32 processes the sensor data.
4. The system identifies conditions that indicate a possible fall.
5. The NEO-6M GPS module obtains the user's location.
6. The SIM800L GSM module can send an emergency message containing the location.
7. Power optimization techniques are used to improve battery usage.
